# uc-online1.1
Complete rewrite of uc-online 1 using C# once more, and uses a different method compared to the releases of the original repo and release's

Uses the steamclient.dll from your Steam install path instead of the steam_api(64).dll in your game's files. Doing this like this means we only need one launcher for both veresions - x86 and x64 - as I tested with multiple games and they all launched and run / worked under this.
